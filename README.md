## Contribute

1. Choose the primary scenario and content type.
2. Copy a template in your language and add content and instructions.
3. Review the format and add an entry link and language label to both homepages.
4. Submit a PR. Maintainer execution is not required; relevance is reviewed in the PR.

Articles and videos need only one Markdown file; complete configurations use directories. Submissions may be in Chinese or English. Credit authors and sources when recommending others’ work.

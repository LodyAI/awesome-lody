## 开始贡献

1. 选择主要场景和内容类型。
2. 复制对应语言的模板，填写内容和使用说明。
3. 对照格式规范检查内容，在两个首页的对应场景下加入链接和语言标注。
4. 提交 PR。无需维护者实际运行验证，具体关联性由 PR 审阅。

文章和视频仅需一个 Markdown 文件；完整配置使用目录。投稿可以只用中文或英文，推荐他人的内容请注明来源和作者。
